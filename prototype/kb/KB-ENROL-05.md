## Bulk enrolment by CSV
Go to **Admin → Users → Import**, download the CSV template, fill one row per user (e-mail, first name, last name, course code) and upload it. Up to 1,000 rows per file. The file must be saved in UTF-8 encoding, otherwise accents cause an encoding error.
