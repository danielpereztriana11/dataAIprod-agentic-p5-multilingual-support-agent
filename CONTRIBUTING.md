# Contributing

1. Follow the setup in the README.
2. Create a branch for a focused change.
3. Implement the change and add meaningful tests when introducing behavior.
4. Run the development checks documented in the README.
5. Open a pull request explaining the problem, the change, and validation performed.

Keep credentials, customer conversations, and private datasets out of version control. Use synthetic examples in documentation and tests.

When adding a runtime dependency, declare it in `pyproject.toml` and document any configuration it needs. Update the product brief when scope changes.
